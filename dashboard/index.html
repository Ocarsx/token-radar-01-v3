How the ranking works

Implied value = TVL × category ratio × growth factor × age factor. The category ratio is the median market-cap/TVL of tokenized protocols in the same category (at least 3 comparables; otherwise the global median 0.214). Growth = 1 + clamp(7d change, −30%, +100%) / 200. Age = 0.70 + 0.15 × min(years listed, 4); no listing date counts as 1.00. The board covers every protocol in the snapshot that records no token, is not a wrapped, staked or bridged product, carries no version suffix and is not an exchange product — 198 protocols, including the 40 on the watchlist (TVL $50M+, no token recorded).

Farm plans are generated from each protocol's category, main chain and size — same plan on this page and in the board data. Gas figures are typical, not live prices. A protocol records no token; that is not proof it will ever issue one. Never pay for a token that does not exist yet.
